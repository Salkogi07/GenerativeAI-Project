## v2.5 · 2026-11-24

**변경 내역**

| 변경 | 이유 |
|---|---|
| 프로토타입에 v2.1~v2.4의 운영 처리 기능을 옮겼어요: 신고 번호(R-·P-)와 운영자 번호 검색, 휴지통(7일, 되살리기), 신고된 리뷰를 운영자가 지우면 작성자 알림, 알림에서 이의 제기, 운영자 이의 제기 화면(받아들이고 되살리기·거절·답변), 키워드 1차 판정. 새 화면 `notices.html`·`appeals.html`·`trash.html` | 와이어프레임은 프로토타입을 복사해 만들어서, PRD v0.7과 화면을 맞추려면 프로토타입에 먼저 있어야 했어요. 메인 앱과 프로토타입은 같은 화면이어야 해요 |
| 프로토타입 `문제없음`이 신고 기록을 지우지 않게 했어요 | 지우면 신고 번호로 다시 찾을 수 없어요. 메인 앱도 신고 기록을 남겨요 |
| 공통 함수 `removeReview`·`removePin`·`restoreTrash`·`keywordCheck`(data.js), `trashCard`·`trashClick`(ui.js)를 두고 핀 상세·운영자 화면이 같이 써요 | 삭제하는 곳마다 휴지통·알림 처리를 따로 두지 않으려고요 |

**확인한 것**: 프로토타입에서 신고(R-4) → 운영자 번호 검색 → 삭제(휴지통으로) → 작성자 마이페이지 안 읽은 알림 1 → 알림에서 이의 제기 → 운영자 `받아들이고 되살리기` → 리뷰가 돌아오고 휴지통 0, 작성자에게 답변 표시까지 눌러 봤어요. 키워드 리뷰는 AI 의심 탭에 `키워드 판정`으로 나와요. 콘솔 오류 0건, 파일 규칙 검사 통과.

**v2.4 대비 변경 내용**

| 구분 | v2.4 | v2.5 |
|---|---|---|
| 프로토타입 화면 | 18개 | 21개 (알림·이의 제기·휴지통 추가) |
| 프로토타입 운영 처리 | 신고·삭제(바로 사라짐) | 신고 번호·휴지통·알림·이의 제기·키워드 판정 |

**PRD와 달라진 점**

- 없음 (D21~D23을 프로토타입에도 반영했어요).

|---|---|

| 핀에도 운영자 `광고 라벨`이 생겼어요. 붙이면 핀 상세·미리보기에 협찬·광고 표시가 붙어요. 광고 라벨·문제없음 모두 그때까지의 신고를 처리한 것으로 보고, 새 신고가 오면 다시 올라와요. 되돌리기 가능 | 핀 신고 버튼을 리뷰와 같게 하려면 핀에도 운영자 광고 라벨이 필요했어요 |
