## v0.5 · 2026-11-17

**변경 내역**

- 메인 앱: Supabase·브이월드 키가 없거나 서버 요청이 실패하면 모든 화면 맨 위에 빨간 경고 띠를 보여 줘요.
- 메인 앱: 자세한 오류를 개발 서버가 `main/logs/app.log`에 저장해요.
- 메인 앱: 핀 찍기 화면에 설명 칸(선택, 최대 500자)을 추가했어요.
- 메인 앱: 핀을 만든 사람이 이름·카테고리·설명을 고치고 핀을 지울 수 있어요. 다른 사람 리뷰가 달린 핀은 지울 수 없어요.
- 메인 앱: 마이페이지에서 프로필 사진을 바꾸거나 지울 수 있어요. 리뷰 카드에도 보여요.
- 메인 앱: "직접 찍은 사진이에요" 체크 칸이 글자 위에 따로 떠 있던 것을 글자 왼쪽에 나란히 놓았어요.
- 문서: README를 나눴어요. 메인 앱 실행 방법·기능·운영자 계정 만드는 법은 [main/README.md](../main/README.md), 변경 이력은 이 파일이에요.

**v0.4 대비 변경 내용**

| 구분 | v0.4 | v0.5 |
|---|---|---|
| 키가 없을 때 | 아무 안내 없이 로그인 화면이 열리고 지도도 정상처럼 보였어요. 로그인 버튼을 누르면 조용히 실패했어요 | 화면 위 띠로 무엇이 안 되는지 보여 주고, 로그인 화면도 "서버에 연결되지 않아 로그인할 수 없어요"라고 알려 줘요 |
| 서버 오류 | 잠깐 뜨는 토스트만 보였고 원인은 남지 않았어요 | 띠가 계속 보이고, 원인은 `logs/app.log`에 남아요 |
| 새 핀 설명 | 핀을 만든 뒤 수정 화면에서만 적을 수 있었어요 | 핀을 처음 만들 때 바로 적을 수 있어요 |
| 핀 수정·삭제 | 설명만 고칠 수 있었고 지울 수 없었어요 | 이름·카테고리·설명을 고치고, 핀을 지울 수 있어요 |
| 프로필 | 닉네임 첫 글자만 보였어요 | 프로필 사진을 올릴 수 있어요 |
| README | 프로토타입·메인 앱·장소 데이터가 한 파일에 있었어요 | 저장소 README(프로토타입), main/README(메인 앱), docs/CHANGELOG(변경 이력)로 나눴어요 |

## v0.4 · 2026-11-15

**변경 내역**

- 회원: Supabase Auth로 가입, 이메일 인증, 로그인, 비밀번호 재설정, 탈퇴를 붙였어요.
- 핀·리뷰·신고·찜 리스트·사진(Storage)을 Supabase에 저장해요.
- 1핀 1리뷰, 신고 3건 자동 숨김, 신규 계정 하루 리뷰 3개 같은 규칙을 서버(RLS·트리거)에서도 검사해요.
- 전국 지역·장소 검색(브이월드)을 붙였어요. 검색한 장소에 핀을 남기면 장소를 저장해요(`save_place`).
- 운영자 리뷰 검토가 실제 데이터로 동작해요. 운영자는 `app_metadata.role = 'admin'`으로 정해요.

**v0.3 대비 변경 내용**

| 구분 | v0.3 | v0.4 |
|---|---|---|
| 메인 앱 데이터 | 장소만 Supabase, 핀·리뷰·리스트는 브라우저 저장 | 회원·핀·리뷰·신고·리스트·사진 모두 Supabase |
| 로그인 | 비밀번호 확인 없는 임시 로그인 | 실제 가입·이메일 인증·로그인 |
| 장소 검색 | 서울 공공데이터 장소만 | 전국 장소·지역(브이월드) |
| 규칙 검사 | 화면에서만 | 화면과 서버 모두 |

## v0.3 · 2026-11-10

**변경 내역**

- 문서 폴더를 버전별로 재구성했어요. `prototype/` → `docs/prototype/`, 와이어프레임 → `docs/wireframe/v0.1~v0.3/`, PRD 파일명 v1.0 → v0.1.
- PRD v0.2와 회색조 와이어프레임 v0.3을 추가했어요.
- 프로토타입
  - 시작 화면 없이 시연 계정으로 바로 지도 홈에 들어가요.
  - 지도 핀 미리보기 카드를 지도의 5분의 2 크기로 키우고 설명·최근 리뷰·작성자를 보여 줘요.
  - 본문 글꼴을 나눔바른고딕으로 바꿨어요.
  - 하단 탭을 홈·피드·마이페이지 3개로 바꾸고, 찜 리스트는 마이페이지에서 들어가요.
  - 피드(장소 사진·리뷰 탭, 정렬, 검색)와 지역 선택 화면을 추가했어요.
  - 마이페이지 활동 칸(찍은 핀·쓴 리뷰·찜 리스트)을 누르면 최근 3개가 펼쳐져요.
  - 핀 찍기에 사진 첨부, 핀 상세에 사진·홈 버튼·하단 탭을 추가했어요.
- 메인 앱(`main/`)
  - 프로토타입 전체 화면을 React + Vite로 옮겼어요.
  - 지도는 Leaflet + OpenStreetMap이에요.
  - 서울 공원, 관악·강서 카페 공공데이터를 정리해 Supabase `places` 테이블에 넣었어요.

**v0.2 대비 변경 내용**

| 구분 | v0.2 | v0.3 |
|---|---|---|
| 폴더 | `prototype/`, `docs/wireframe/` 한 단계 | `docs/` 아래 버전별 폴더 |
| 기획 문서 | PRD v0.1(확정본) | PRD v0.2 추가 (와이어프레임 v0.1~v0.3 반영) |
| 첫 화면 | 시작 화면 | 시연 계정으로 바로 지도 홈 |
| 하단 탭 | 홈·리스트·검색·내 정보 | 홈·피드·마이페이지 |
| 새 화면 | - | 피드, 지역 선택, 내 활동 |
| 메인 앱 | 없음 | React 앱, 실제 지도(OSM), 공공데이터 장소 |
