- 작업 단계 하나를 마치거나 수정을 적용하면 **버전을 0.1 올리고** 이 파일 맨 위에 새 버전을 적어요.

- PRD와 달라지는 결정이 생기면 그 버전에 **PRD와 달라진 점**을 적고, [prd/DECISIONS.md](prd/DECISIONS.md)에도 같은 내용을 추가해요.

## v0.6 · 2026-11-17

팀에서 정리한 수정 요청 14건을 메인 앱에 반영했어요.

**변경 내역**

| 변경 | 이유 |
|---|---|
| 핀·리뷰 사진을 누르면 전체 화면으로 크게 보고, 옆으로 넘겨 볼 수 있어요 | 작은 썸네일만 있어서 사진 내용을 확인하기 어려웠어요 |
| 지도를 OpenStreetMap에서 **브이월드 배경지도**로 바꿨어요 | 네이버 지도 일반 버전처럼 한글 이름이 보이는 깔끔한 지도를 원했어요. 네이버 지도 API는 결제 수단 등록이 필요해서, 이미 쓰고 있는 브이월드 키로 비슷한 지도를 띄웠어요 |
| 지도를 한국 범위로 고정했어요(최대로 축소해도 옆으로 반복되지 않아요) | 최대로 축소한 지도가 옆으로 반복되고, 넘어간 곳에서는 찍은 핀이 사라져 보였어요 |
| 지도를 확대·축소하면 핀 크기가 따라 바뀌어요(100% → 80% → 60%) | 축소했을 때 핀이 겹쳐 지도가 복잡해 보였어요 |
| 핀 안에 **카테고리 아이콘**(☕🍴🖼️🌳📍)을 넣었어요. 카테고리 목록은 **운영자만** 추가·이름 변경·아이콘 변경·삭제해요 | 지도에서 핀 종류를 바로 구분하고 싶었어요. 카테고리를 사용자가 마음대로 늘리지 못하게 운영자가 관리하기로 했어요 |
| **내 핀은 파란색, 다른 사람 핀은 회색**으로 보여요 | 내가 찍은 핀을 지도에서 찾기 어려웠어요 |
| 핀을 찍거나 고칠 때 **"협찬·대가를 받았어요"**를 체크할 수 있고, 체크한 핀은 설명 위에 협찬·광고 표시가 붙어요 | 리뷰만 협찬 표시가 있고, 협찬받아 남긴 핀은 구분할 수 없었어요 |
| 핀 찍기 화면의 **근처 장소 연결을 뺐어요**. 장소 연결은 검색에서 장소를 고르고 핀을 남길 때만 해요 | 근처 장소 목록이 헷갈리고 필요 없다는 판단이었어요 |
| 핀 찍기 중에 근처 핀을 보러 갔다가 돌아와도 **작성하던 내용이 남아 있어요** | "근처에 핀이 있어요 → 보기"를 눌렀다 돌아오면 입력한 내용이 사라졌어요 |
| 핀 상세의 "지도에서 크게 보기"를 **"길찾기"**로 바꿨어요. 네이버 지도 **대중교통 길찾기**가 바로 열려요 | 길을 찾을 때 익숙한 네이버 지도로 가고 싶었고, 대중교통 경로가 필요했어요 |
| 운영자 리뷰 검토의 "신고 누적" 탭을 **"신고"**로 바꾸고, 신고가 1건이라도 있으면 보여요 | 신고해도 운영자에게 전달되지 않았어요. 신고 3건 이상인 리뷰만 보여 줘서 1~2건 신고는 어디에도 보이지 않았어요 |
| 지도 아래 **손잡이를 끌어서 지도 높이**를 바꿀 수 있어요(검색 결과, 핀 찍기, 핀 상세, 리스트) | 목록과 지도가 같이 있을 때 지도가 작아서 보기 어려웠어요 |
| 핀·리뷰를 저장한 뒤 뒤로 가기를 누르면 작성 화면이 아니라 그 전 화면으로 가요 | 저장 뒤 뒤로 가기를 누르면 방금 저장한 작성 화면이 다시 열렸어요 |
| 협찬 체크 칸 모양을 바로잡고, "직접 찍은 사진이에요"와 "필수" 사이를 띄웠어요 | 체크 칸이 글자 위로 따로 떠서 깨져 보였고, "필수"가 글자에 붙어 있었어요 |
| DB: `pins.ad` 칸, `categories` 테이블(누구나 읽기, 운영자만 수정)을 추가했어요 | 핀 협찬 표시와 운영자 카테고리 관리를 서버에 저장하고, 권한을 서버(RLS)에서 막기 위해서예요 |
