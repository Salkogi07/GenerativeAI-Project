# PRD v0.2 이후 바뀐 결정

[PRD v0.2](<Pin it! PRD v0.2.pdf>)(2026-11-10)를 쓴 뒤 만들면서 바뀐 결정을 모은 문서예요. PRD는 PDF라 바로 고칠 수 없어서, 다음 PRD 버전을 쓸 때 이 목록을 반영해요. D01~D18은 [PRD v0.3](<Pin it! PRD v0.3.pdf>)·[v0.4](<Pin it! PRD v0.4.pdf>)에, D19는 [v0.5](<Pin it! PRD v0.5.pdf>)에, D20은 [v0.6](<Pin it! PRD v0.6.pdf>)에, D21~D26은 [v0.7](<Pin it! PRD v0.7.pdf>)에 반영했어요.

## 관리 규칙

- 구현하다가 PRD와 다르게 정한 것이 생기면 아래 표에 한 줄을 추가해요. 번호는 이어서 붙여요(D19, D20 …).
- 같은 작업의 [변경 이력](../CHANGELOG.md) 버전에도 "PRD와 달라진 점"으로 적어요.
- 이유를 모르는 결정은 지어내지 말고 `기록 없음 (팀 확인 필요)`로 적어요.
- **PRD 반영** 칸은 다음 PRD에 반영하면 `반영함 (PRD v0.3)`으로 바꿔요.
- 결정을 다시 바꾸면 줄을 지우지 않고, 새 줄을 추가한 뒤 이전 줄의 상태를 `바뀜 → D번호`로 적어요.

## 그대로 지키는 PRD 규칙

바뀌지 않았지만 구현할 때 자주 확인하는 규칙이에요.

- 1핀 1리뷰, 신고 3건(서로 다른 계정) 자동 숨김, 가입 7일 이내 계정은 하루 리뷰 3개
- 사진 최대 3장·장당 5MB, 핀 이름 30자·설명 500자·리뷰 1000자
- 30m 안에 다른 핀이 있으면 기존 핀 안내
- 리스트는 기본 비공개, 공유 링크는 무작위 토큰
- 운영자 권한은 `app_metadata.role = 'admin'`과 RLS로 막아요
- 사용자에게는 AI 판정을 보여 주지 않아요
