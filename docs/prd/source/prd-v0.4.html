1. 프로젝트 소개

Pin it!은 광고 여부가 드러난 리뷰와 함께 위치 핀·찜 리스트를 찾고 공유하는 모바일 웹 서비스예요. 대상 기기는 Galaxy S26(360×780 dp)이고 모바일 전용이에요. [v0.3] 프로토타입(브라우저 저장 시연용)과 별개로, 실제 서버에 저장하는 메인 앱(베타)을 만들었어요. [v0.4] 메인 앱은 https://generative-ai-project-three.vercel.app/ 에서 휴대폰으로 바로 열려요.

기획서와 실습이 다르면 실습 2·3을 따르는 원칙은 그대로예요. PRD와 실제 구현이 다르면 이 문서가 구현을 따라 고쳐요.

구분내용
이름[확정] Pin it!
유형[확정] ② 모델 구현형. AI 광고성 리뷰 탐지를 직접 연결해 작동하게 만들어요.
한 줄 설명장소·키워드로 핀과 리스트를 검색하고, 광고인지 표시된 리뷰를 함께 보는 위치 공유 웹 서비스예요.
컨셉지도 어디에나 공개 핀을 남기고, 마음에 드는 핀은 찜 리스트로 모아요. 리스트는 공개·비공개로 관리해요.
목표믿을 만한 방문 정보를 찾고, 고른 장소를 주제별 리스트로 정리·공유하게 도와요.

2. 사용자·문제·가치

v0.2와 같아요. 광고 후기 규모와 공개 설정 위험은 근거가 있고, 불편의 강도·위치 핀 수요·리뷰 신뢰 장치의 효과는 사용자 테스트로 확인해요.

7-5. [확인 필요] 새로 정할 것

  • AI 광고성 리뷰 탐지 구현 여부와 일정: Edge Function이 아직 없어요. 12주차 테스트 범위에 넣을지 정해야 해요.
  • 인증 메일: Supabase 기본 메일은 팀원 주소로만, 시간당 약 2통 보내요. 사용자 테스트 5명이 가입하려면 외부 메일(SMTP)을 설정해야 해요.
  • [v0.4] 배포 주소를 Supabase 인증 주소(Site URL·Redirect URLs)에 등록했는지 확인해야 해요. 안 하면 휴대폰에서 받은 인증 메일 링크가 열리지 않아요.
  • 브이월드 키 노출: 전국 검색과 지도 타일이 브라우저에서 키를 써요. 숨기려면 한국 리전 서버를 거쳐야 하는데, 지도가 느려지고 비용이 늘어요.
  • 리뷰 수정 허용 여부: 지금은 삭제만 돼요. 허용하면 수정한 리뷰도 AI 재판정을 할지 정해야 해요.
  • 회원 탈퇴 후 핀·리뷰 처리: 지금은 남기고 작성자를 '알 수 없음'으로 보여줘요. 삭제할지 익명으로 남길지 정해야 해요.
  • '도움돼요' 기능: Could지만 아직 없어요. 만들지 뺄지 정해야 해요.
  • 이유 기록이 없는 결정(D05 피드·지역 선택, D06 핀 수정·삭제, D07 프로필 사진, D16 지역 범위, D18 핀 삭제)의 이유를 팀이 확인해 DECISIONS.md에 적어야 해요.

v0.2의 확인 필요 항목 중 '핀 찍기 위치 지정'(누르기 + 끌기로 구현), '시작 화면 유지'(없앰), '카테고리 기타'(운영자 관리로 해결), '새 기능 등급'(3-1에 반영)은 정리됐어요.
