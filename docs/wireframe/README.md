## v0.5: 회색조 프로토타입 (핀 신고·운영자 삭제 반영)

v0.4와 같은 방식이에요. 지금 프로토타입을 다시 복사하고 [css/wireframe.css](v0.5/prototype/css/wireframe.css)를 붙였어요. 변경 이력 v1.9(2026-11-24) 기준이고, PRD v0.6이 이 화면 구성을 따라요.

- 시작: [v0.5/prototype/pages/index.html](v0.5/prototype/pages/index.html)
- 화면: v0.4와 같은 18개

**v0.4 대비 바뀐 점**

| 영역 | v0.4 | v0.5 |
|---|---|---|
| 핀 상세 | 위쪽에 홈·공유 | + ⋮ 메뉴: 남의 핀 신고, 운영자는 핀 삭제 |
| 핀 신고 | 없음 | 바텀시트, 이유 4개 중 하나 |

| 리뷰 검토 카드 | 광고 라벨 · 숨김 · 문제없음 | + 삭제. 핀 신고 탭은 핀 보기 · 핀 삭제 |
| 협찬·대가 체크 박스 | 긴 화면에서 눌려 글이 넘침 | 글이 박스 안에 들어감 |

## v0.2: 화면별 HTML + 주석 PDF

v0.1을 화면마다 파일 하나로 나누고, 한 화면의 여러 상태(입력 중, 결과 없음, 미인증 등)도 따로 그렸어요. PRD v0.1(확정본)을 기준으로 했어요.

- **HTML:** [v0.2/html/index.html](v0.2/html/index.html)을 열면 화면 목록과 정상 흐름이 나와요. 화면 파일은 `pages/`에 있어요.
- **PDF:** [PinIt_Wireframe_v0.2.pdf](v0.2/html/PinIt_Wireframe_v0.2.pdf)는 화면마다 주석이 달려 있어요. HTML보다 이전 내용이고, 원본이 없어 다시 출력할 수 없어요.

**정상 흐름**

- 가입: 시작(S-00) → 약관 동의 → 정보 입력 → 이메일 인증(S-02) → 로그인(S-01)
- 사용: 검색(S-05) → 핀 상세(S-07) → 찜(S-11) → 핀 찍기(S-06) → 리뷰(S-09) → 리스트 공유(S-12 → S-13)

**화면 (24개 파일)**

| 구분 | 화면 |
|---|---|
| 계정 | S-00 시작, S-01 로그인, S-01 로그인·이메일 미인증, S-02 회원가입 1/3 약관 동의, 2/3 정보 입력, 3/3 이메일 인증, S-03 내 정보 |
| 지도·검색 | S-04 지도 홈, S-05 검색 입력 중, 검색 결과 핀 탭, 리스트 탭, 결과 없음 |
| 핀·리뷰 | S-06 핀 찍기, S-07 핀 상세, S-07a 리뷰 신고 바텀시트, S-08 핀 설명 수정, S-09 리뷰 작성, 리뷰 작성 제한 |
| 찜 리스트 | S-10 내 찜 리스트, S-11 찜하기, S-12 찜 리스트 상세, S-13 공유 찜 리스트 보기, 공유 보기·볼 수 없음 |
| 운영자 | S-14 리뷰 검토 |

**v0.1 대비 바뀐 점**

- 시작 화면(S-00)과 약관 동의 단계를 추가했어요. 회원가입이 3단계(약관 동의 → 정보 입력 → 이메일 인증)가 됐어요.
- 이메일 미인증 로그인, 검색 입력 중·결과 없음, 리뷰 작성 제한, 볼 수 없는 공유 리스트 같은 상태를 각각 한 화면으로 그렸어요.
- 기준 기기를 Galaxy S26(360×780dp)으로 바꿨어요.

## v0.1: 첫 와이어프레임

화면 전체를 HTML 파일 하나에 담은 첫 설계예요. 휴대폰 화면 하나가 가운데에 뜨고, 버튼을 누르면 다음 화면으로 넘어가요.

**화면 (15개)**

| 번호 | 화면 | 번호 | 화면 |
|---|---|---|---|
| S-01 | 로그인 | S-08 | 핀 설명 수정 |
| S-02 | 회원가입 | S-09 | 리뷰 작성 |
| S-03 | 내 정보 | S-10 | 내 찜 리스트 |
| S-04 | 지도 홈 | S-11 | 찜하기 |
| S-05 | 검색 결과 | S-12 | 찜 리스트 상세 |
| S-06 | 핀 찍기 | S-13 | 공유 찜 리스트 보기 |
| S-07 | 핀 상세 | S-14 | 리뷰 검토 (운영자) |
| S-07a | 리뷰 신고 | | |

**특징**

- 하단 탭은 **홈·검색·리스트·내 정보** 4개예요.
- 로그인이 필요한 동작(찜, 리뷰 쓰기)을 누르면 "로그인이 필요해요" 안내가 떠요.
- 예외 상황을 바텀시트로 보여 줘요: 리뷰 신고, 새 리스트 만들기, 리뷰 작성 제한, 이미 등록된 장소, 검색 결과 없음.
- 핀 찍기에서 이름(필수)·근처 장소 연결(선택)·설명·사진을 받아요.
- 리뷰 검토(S-14)는 운영자만 들어갈 수 있다고 표시해요.
