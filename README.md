# Pin it!

광고인지 보이는 리뷰로 장소를 고르고, 가게가 아닌 곳도 핀으로 남겨 리스트로 공유하는 모바일 웹 서비스예요.
이 저장소에는 기획 문서, 브라우저에서 바로 써 볼 수 있는 프로토타입(`docs/prototype/`), 그리고 실제 서비스로 만들고 있는 메인 앱(`main/`, React + Supabase)이 있어요.

## 바로 써 보기

### 👉 <https://salkogi07.github.io/GenerativeAI-Project/>

이 링크는 **프로토타입**을 열어요. 메인 앱은 아직 배포하지 않았고, [메인 앱 실행하기](#메인-앱-실행하기-main)를 따라 내 컴퓨터에서 실행할 수 있어요. 화면과 사용법은 둘이 같아요.

- 링크를 열면 바로 지도 홈이 나와요. 로그인이나 회원가입 없이 핀을 찍어 볼 수 있어요.
- 휴대폰으로 열면 앱처럼 전체 화면으로 보여요. PC에서는 가운데에 휴대폰 폭으로 보여요.
- PC에서 휴대폰 크기로 보려면 Chrome에서 F12를 누르고 기기 툴바(Ctrl+Shift+M)를 켜세요.

### 시연 계정

처음 열면 일반 사용자 계정으로 자동 로그인돼요. 운영자로 바꾸려면 **마이페이지 → 로그아웃** 뒤 로그인 화면에서 이메일만 입력하고 **로그인**을 누르면 돼요. 지금은 비밀번호를 확인하지 않아요.

| 계정 | 이메일 | 할 수 있는 것 |
|---|---|---|
| 일반 사용자 | `demo@pinit.kr` (빈칸으로 둬도 이 계정) | 핀 찍기, 찜, 리뷰, 신고, 리스트 공유 |
| 운영자 | `admin@pinit.kr` | 일반 기능 + 리뷰 검토 화면 |

## 사용 설명서

### 1. 시작하기

- 링크를 열면 시작 화면 없이 `demo@pinit.kr`로 로그인된 채 지도 홈이 열려요.
- **회원가입:** 로그인 화면에서 가입 화면으로 갈 수 있어요.
  - 약관 동의 → 정보 입력(닉네임·이메일·비밀번호) → 이메일 인증 순서로 가입해요.
  - 시연 환경에는 실제 메일이 오지 않아요. 마지막 화면의 **인증 완료하고 로그인하기**가 인증 링크를 누른 것을 대신해요.

### 2. 지도에서 장소 찾기 (홈)

- 지도의 핀을 누르면 아래에 미리보기 카드가 떠요. 지도의 약 5분의 2 크기로 이름, 종류·리뷰 수·찜 수, 설명, 최근 리뷰 2개(협찬·광고 표시 포함), 작성자가 보여요. 카드를 누르면 핀 상세로 가요.
- 위쪽 칩(카페·맛집·전시·산책)으로 종류를 골라 볼 수 있어요. 같은 칩을 한 번 더 누르면 전체가 보여요.
- 파란 핀은 가게에 연결된 핀이고, 검은 핀은 벤치·산책길 같은 위치 핀이에요.
- 오른쪽 위 지역 이름(**성수동 ⌄**)을 누르면 지역 선택 화면에서 동네를 검색해 고를 수 있어요. 지금은 성수동에만 시연 데이터가 있어서, 다른 지역은 지도만 옮겨요.
- 아래 탭은 **홈·피드·마이페이지** 3개예요. 핀 상세·핀 찍기·지역 선택·내 활동·찜 리스트 화면에도 아래 탭이 보이고, 글자를 입력하는 동안에는 숨어요.

### 3. 검색하기

- 홈 위쪽 검색창을 누르고 "카페", "산책", "벤치"처럼 입력해요.
- 결과는 **핀** 탭과 **리스트** 탭으로 나뉘어요.
  - **핀** 탭의 "아직 핀이 없어요" 장소는 **핀 남기기**로 첫 핀을 만들 수 있어요.
  - **리스트** 탭에는 공개 리스트만 나와요.
- 결과가 없으면 **첫 핀 남기기**나 **범위 넓히기**를 눌러요.

### 4. 핀 찍기

1. 홈 오른쪽 아래의 **핀 찍기**를 눌러요.
2. 지도를 눌러 위치를 정해요. 주황 핀을 끌어서 옮길 수도 있어요.
3. 핀 이름을 직접 적고 카테고리를 골라요. 사진도 3장까지 올릴 수 있어요(올리면 "직접 찍은 사진이에요" 체크 필수).
4. 가게라면 **근처 장소 연결**에서 장소를 골라요. 벤치·산책길 같은 곳이면 "연결 안 함"으로 둬요.
5. **핀 저장**을 누르면 모든 사람의 지도에 보여요.

- 이미 핀이 있는 장소를 고르면 새로 만들지 않고 그 핀으로 안내해요.
- 30m 안에 다른 핀이 있으면 그 핀을 쓸지 물어봐요.

### 5. 리뷰 읽고 쓰기 (핀 상세)

- 핀 상세 위쪽의 집 모양 버튼을 누르면 바로 지도 홈으로 가요.
- 리뷰 맨 위의 주황색 **협찬·광고** 표시는 대가를 받고 쓴 리뷰라는 뜻이에요.
- **리뷰 쓰기**
  - 본문을 쓰고, 협찬·대가를 받았다면 꼭 체크해요.
  - 사진은 3장까지 올릴 수 있고, 올리면 "직접 찍은 사진이에요"를 체크해야 해요.
- **작성 제한**
  - 한 장소에는 리뷰를 하나만 쓸 수 있어요.
  - 가입한 지 7일이 안 된 계정은 하루 3개까지 쓸 수 있어요. 시연 계정이 여기에 해당해요.
- **신고하기**
  - 다른 사람 리뷰의 **⋮** → **신고하기** → 이유를 골라 신고해요.
  - 서로 다른 계정 3명이 신고하면 리뷰가 "검토 중"으로 가려져요.
- 내 리뷰의 **⋮**에서는 삭제할 수 있어요.

### 6. 찜하고 리스트로 공유하기

1. 핀 상세 아래의 **♡**를 눌러 담을 리스트를 골라요. 여러 개를 한 번에 고를 수 있고, 새 리스트도 바로 만들 수 있어요.
2. **마이페이지** 위쪽의 **찜 리스트** 칸을 누르면 아래에 최근 리스트 3개가 펼쳐져요. 리스트를 누르거나 **전체 보기**로 모든 리스트를 열어요.
3. 리스트는 처음에 **비공개**예요. 스위치를 켜서 **공개**로 바꾸면 **공유 링크 복사**를 누를 수 있어요.
4. 복사한 링크를 열면 로그인 없이 리스트를 볼 수 있어요.

- 다시 비공개로 바꾸면 같은 링크로 열어도 "볼 수 없는 리스트예요"가 나와요.

### 7. 피드

- 아래 탭의 **피드**에서 장소들을 사진으로 모아 봐요.
- **장소 사진** 탭: 장소마다 핀 사진과 리뷰 사진을 보여 줘요. **인기 많은 순**(찜 수, 같으면 리뷰 수)일 때는 순위가 붙어요. 누르면 그 장소의 리뷰로 바로 가요.
- **리뷰** 탭: 모든 리뷰를 모아 봐요. 누르면 핀 상세의 그 리뷰로 가요.
- 정렬은 **인기 많은 순·인기 적은 순·최신순·오래된 순** 중에서 골라요.
- 위쪽 검색창으로 피드를 걸러 볼 수 있어요. 장소 사진 탭은 장소 이름·카테고리·설명·작성자, 리뷰 탭은 리뷰 내용·장소 이름·작성자로 찾아요.

### 8. 마이페이지

- 닉네임 수정, 위치 정보 이용 켜기·끄기, 약관 보기, 로그아웃, 회원 탈퇴를 할 수 있어요.
- 위쪽 숫자 칸(**찍은 핀·쓴 리뷰·찜 리스트**)을 누르면 바로 아래에 최근 3개가 펼쳐져요. 다시 누르면 접히고, **전체 보기**로 전체 목록을 열 수 있어요.

### 9. 운영자: 리뷰 검토

1. `admin@pinit.kr`로 로그인해요.
2. **마이페이지** → **리뷰 검토**를 열어요.

- 대기열은 세 가지예요.
  - **AI 의심:** AI가 광고로 의심한 리뷰
  - **신고 누적:** 신고가 3건 이상 쌓인 리뷰
  - **미판정:** AI 판정에 실패한 리뷰
- 처리 버튼은 세 가지예요. 처리한 직후에는 **되돌리기**를 누를 수 있어요.
  - **광고 라벨:** 사용자 화면에 협찬·광고 표시가 붙어요.
  - **숨김:** 리뷰를 가려요.
  - **문제없음:** 대기열에서 빼고, 신고로 가려졌던 리뷰를 다시 보여요.
- AI 판정 결과(확신도·이유)는 고정된 **예시 데이터**예요. 화면에도 '예시 데이터'로 표시돼요. 일반 사용자에게는 AI 판정이 보이지 않아요.

## 알아 둘 점

- **데이터**
  - 지도와 리뷰는 성수동 시연용 가상 데이터예요.
  - 내가 만든 핀·리뷰·리스트는 **지금 쓰는 브라우저에만** 저장돼요.
  - 그래서 공유 링크를 다른 기기나 다른 브라우저에서 열면 "볼 수 없는 리스트예요"가 나와요.
- **처음 상태로 되돌리기:** F12 → Application → Local Storage에서 `pinit.`으로 시작하는 항목을 지우고 새로고침해요.
- **지도:** 프로토타입은 실제 지도 이미지 없이 격자 배경 위에 핀만 보여요. 메인 앱은 OpenStreetMap 실제 지도를 써요.
- **로그인:** 비밀번호 확인과 이메일 인증 확인은 나중에 붙일 예정이에요.

## 내 컴퓨터에서 실행하기

### 프로토타입

- **파일로 열기:** 저장소 맨 위의 `index.html`을 브라우저로 열면 돼요.
- **로컬 서버로 열기:** 저장소 맨 위에서 아래 명령을 실행하고 <http://localhost:8000> 을 열어요.

  ```sh
  python -m http.server 8000
  ```

### 메인 앱 실행하기 (main)

[Node.js](https://nodejs.org) 20 이상이 필요해요.

1. `main/.env.example`을 복사해서 `main/.env.local`을 만들고, Supabase 값을 넣어요. 값은 Supabase 대시보드 **Project Settings → API Keys**에 있어요.

   ```
   VITE_SUPABASE_URL=https://<프로젝트 ID>.supabase.co
   VITE_SUPABASE_KEY=sb_publishable_...
   ```

   - publishable 키는 브라우저에 공개돼도 되는 키예요. **secret(service_role) 키와 DB 비밀번호는 절대 넣지 마세요.**
   - `.env.local`은 git에 올라가지 않아요.
2. 아래 명령을 실행하고 <http://localhost:5173> 을 열어요.

   ```sh
   cd main
   npm install
   npm run dev
   ```

**메인 앱에서 진짜인 것과 아직 시연용인 것**

| 진짜 | 아직 시연용 (브라우저에만 저장, 프로토타입과 같음) |
|---|---|
| 지도: OpenStreetMap | 로그인·회원가입 (누르면 바로 로그인) |
| 장소 검색, 핀 찍기의 "근처 장소 연결": Supabase의 공공데이터 장소 | 핀·리뷰·찜 리스트 |
| | AI 광고 판정 (예시 데이터) |

시연용 기능은 로그인 → 핀 → 리뷰 → 리스트 순서로 Supabase로 옮길 예정이에요.

## 장소 데이터 (공공데이터)

메인 앱의 장소는 아래 공공데이터를 정리해서 Supabase `places` 테이블에 넣은 거예요. 앱의 **마이페이지 → 장소 데이터 출처**에도 표시돼요.

| 데이터 | 장소 수 | 비고 |
|---|---|---|
| 서울특별시 주요 공원현황 (2026 하반기) | 152 | 좌표 포함. 위도·경도가 뒤바뀐 행 등은 스크립트가 고쳐요 |
| 서울특별시 관악구 카페및커피숍 현황 (2022) | 636 | 주소만 있어서 브이월드 지오코더로 좌표를 구했어요 |
| 서울특별시 강서구 카페(커피숍) 현황 (2025.8.5. 기준) | 809 | 위와 같음 |

**데이터를 다시 만들거나 추가하려면**

1. 원본 JSON을 `data/raw/`에 넣어요.
2. 저장소 맨 위의 `.env.local`(git에 올라가지 않음)에 브이월드 인증키를 `VWORLD_KEY=...`로 넣어요. 카페처럼 좌표가 없는 데이터만 필요해요.
3. `python scripts/build_places.py`를 실행해요. 정리 규칙 검사는 `python scripts/build_places.py --selftest`예요.
4. 처음 한 번은 Supabase **SQL Editor**에서 `supabase/migrations/` 안의 SQL을 실행해 테이블을 만들어요.
5. 만들어진 `supabase/seed.sql`을 SQL Editor에서 실행해요. 같은 장소는 덮어써서 여러 번 실행해도 괜찮아요.

## 폴더 구조

```
index.html          프로토타입 지도 홈으로 이동
main/               메인 앱 (React + Vite + Supabase)
├─ src/pages/       화면 (프로토타입 화면과 1:1)
├─ src/ui/          공통 UI · 지도
├─ src/lib/         시연 데이터 저장소 · 장소(Supabase) 조회
└─ src/styles/      프로토타입 CSS 그대로 + main 전용
supabase/           places 테이블 SQL(migrations) · 장소 데이터(seed.sql)
scripts/            build_places.py (공공데이터 → 장소 데이터)
data/               raw/ 원본 공공데이터 · places.json · 좌표 캐시
docs/
├─ prd/             PRD v0.2 (최신) · v0.1 (확정본)
├─ prototype/
│  ├─ pages/        화면 HTML (index.html → 지도 홈)
│  ├─ css/          common.css(공통) · pages/(화면별)
│  └─ js/           core·data·ui·map.js(공통) · pages/(화면별)
└─ wireframe/
   ├─ v0.1/         이전 와이어프레임 (HTML 1개)
   └─ v0.2/html/    HTML 와이어프레임 · PDF
```

기획 문서 안내는 [docs/README.md](docs/README.md)에 있어요.
